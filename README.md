# My Shop - Responsive E-commerce Website

This is a responsive online shopping website created using HTML, CSS and JavaScript.

## Features
- Responsive Design (Works on Mobile, Tablet & Desktop)
- Product Grid System using CSS Grid
- Sticky Header with Cart
- Product Hover Effect
- Clean and Modern UI

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (for cart functionality)

## Media Queries Used
- 900px for Tablet View (2 columns)
- 600px for Mobile View (1 column)

## How to Run
Just open `index.html` in browser.
